# Logo Files

Logos placed here appear top right on the distributor estimate, contractor quote and
quote comparison PDFs, and on the browser print view. Missing files are skipped.

- `henry-logo.png` - Henry (trimmed, transparent background, made from `henry-carlisle-logo-1.jpg`)
- `enduraroof-logo.png` - Enduraroof (not added yet)

Use PNG, ideally with a transparent background and the empty margin trimmed off.
About 400-600px wide is plenty; the PDFs draw logos 40pt (about 0.55") tall.
